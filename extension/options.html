Amplifier Browser Bridge

This extension connects to a hub process running on your tailnet and lets an agent observe/drive this browser. Nothing is committed to source for this -- configuration lives only in this browser's local extension storage.

Use a tailnet IP literal, not a MagicDNS name (MagicDNS resolution is unreliable per-device -- see docs/designs/browser-bridge.md section 4). The path defaults to "/device" if you leave it off.
