Privacy policy

Last updated: 2026-08-07

This extension is fundamentally different from a typical browser extension's privacy story. It exists to let an AI agent read and act on the pages you browse, at your own direction, by design. There is no way to make that sound narrow without being dishonest about it -- read this policy alongside SECURITY.md before installing.

What data this extension can access

When commanded to by the hub you configure (see below), this extension can read the content of any page you are viewing -- text, form fields, page structure -- and can dispatch clicks, keystrokes, and navigation as if you had performed them yourself. It requests the <all_urls> host permission specifically because this capability is not scoped to any particular site; it is available on whatever page you have open when an agent issues a command.

Where that data goes

This extension has exactly one network destination: the hub -- a small program that you install and run, at an address you configure on this extension's options page. There is no telemetry, no analytics, and no first-party server operated by the maintainers that this extension talks to. Whatever the hub does with data it receives is a property of your own deployment, not of this extension's code -- if you run the hub on a machine or account you do not control, that operator can see everything this extension reads and everything it is commanded to do.

The hub, and who can command this extension

The hub can be reached by anything that holds its shared token and can route a network connection to it -- typically your own Tailscale network. See SECURITY.md for the full, current accounting of what protects that boundary (the token is the load-bearing one in most deployments, not the tailnet by itself).

Local storage (chrome.storage.local)

The extension stores, locally on your device only: the hub URL and token you enter on its options page, and a randomly generated device identifier. None of this leaves your device except as part of the WebSocket connection you configured to your own hub.

What this extension does NOT do

  • It does not send data to any server operated by the project's maintainers.
  • It does not include any analytics, crash reporting, or usage-tracking library.
  • It does not read or transmit anything unless a command from your configured hub asks it to.

Permissions

See docs/permission-justifications.md in the source repository for the full, long-form reasoning behind every permission this extension requests, including an honest accounting of which ones could and could not be narrowed.

Contact

Issues and questions: please file an issue on the project's GitHub repository. To report a security vulnerability, see SECURITY.md -- do not use a public issue for that.
